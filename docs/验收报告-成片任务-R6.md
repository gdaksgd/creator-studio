## 1. 本次交付

### 供应商注册表

- `src/config/providers.ts` 定义能力、运行时、免费/付费、计价单位、说明与 fallback：
  - Edge TTS（配音，本地 worker，免费）
  - 本地规则引擎（平台规则，本地，免费）
  - B站公开接口（平台数据，API，免费但限流）
  - DeepSeek（LLM，API，付费；单价按供应商账单，不猜价格）
  - 人工复核（人工，免费，时间成本不折算）
- 任务详情「成本」→「供应商」可查看注册表与 TTS worker 实时状态。
- 付费 provider 标注「首次使用需人工确认」；当前 run 流水线不会自动调用付费 provider，不会自动扣费。

### 成本账本

- Dexie v10 `runCosts`：provider、能力、操作、units/unitLabel、估算/实际成本、来源、时间、batchId。
- 每次生成配音记录一条 Edge TTS 成本（字符数 + ¥0.00）；未记录金额显示「未记录」，不补 0。
- 任务详情「成本」卡显示实际合计、最近 5 条与供应商口径。
- 批量详情汇总该批 run 的成本。

### 批量任务

- Dexie v10 `runBatches`：标题、items、状态、并发、actor、时间。
- 成片任务页「批量创建」：多选脚本（默认前 5 条）、并发 1–3；每个脚本生成独立 run。
- 批量执行只做发布前预检；并发执行，单条失败自动重试 2 次。
- 批量状态：待执行/执行中/已完成/部分失败/失败；条目状态：待执行/预检中/已预检/失败。
- 批量详情：逐条显示 run 标题、平台/版本、预检次数、run 状态、阻塞项、错误与跳转链接。
- 失败项可「重试失败项」；预检完成但 run 阻塞时，条目仍标「已预检」，避免把门禁状态和批量执行状态混为一谈。

### 备份 v4

- 本地备份版本升级到 **v4**，包含 `runs`、`runCosts`、`runBatches`。
- 旧 v1–v3 备份仍可读取/恢复；预览显示成本/批量计数。
- 媒体文件仍不进备份；云同步仍不包含 runs/costs/batches。

## 4. 已知限制

- 批量只执行「创建 + 发布前检查」；不会自动准备素材、生成配音/字幕或复核，因此批量完成时 run 仍可能阻塞。
- 批量执行是客户端任务；关闭页面会中断未完成项，重新打开后可继续执行待执行项。
- 成本账本目前只记录真实的 TTS 调用（本地免费，¥0.00）；DeepSeek 等付费 provider 未接入 run 流水线，也没有拿到 token 账单，实际成本显示为「按供应商账单」。
- 供应商注册表是静态配置；只有 Edge TTS worker 有实时健康检查，DeepSeek/B站接口的可用性由各自调用/检查项表达。
- 付费 provider 的「首次使用确认」目前是注册表口径说明；没有自动扣费路径。
- 备份 v4 不含配音/视频媒体文件；换设备后媒体需要重新生成。
- 云同步仍只同步选题/脚本/素材元数据，不含 runs/costs/batches。
- R7（剪映/EDL/FFmpeg 成片交接与质检）归类为后续升级方向，未实现。
