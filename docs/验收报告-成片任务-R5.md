## 1. 本次交付

### 流水线 v2

- 新增 `game-longform@2` / `game-shortform@2`，7 阶段：脚本锁定 → 发布前检查 → 素材清单 → **配音** → **字幕** → 人工复核 → 导出交接包。
- `game-longform@1` / `game-shortform@1` 保留；旧 run（无 `pipelineId` 或 `pipelineVersion: "1"`）继续按 5 阶段读取，不会突然要求 TTS。
- 新建长/短版任务默认使用 v2；营销素材包仍为 v1 三阶段。

### 本地 TTS worker

- `tools/tts-worker/worker.py`：本地 Edge TTS HTTP worker，监听 `127.0.0.1:3101`。
- `GET /health` 返回 provider/voices；`POST /synthesize` 返回 MP3（base64）与 TTS `SentenceBoundary` 句级时间戳。
- 启动脚本：`powershell -NoProfile -ExecutionPolicy Bypass -File tools/tts-worker/start-tts-worker.ps1`。
- worker 不可用时：配音阶段阻塞、生成按钮禁用、不生成假音频。
- 本次验收环境：Python 3.14 + `edge-tts 7.3.1`（`logs/tts-venv`，已 gitignore）。

### 媒体与数据

- Dexie v9 新增本机 `runMedia` 表，音频 Blob 只存本机 IndexedDB；不出现在本地备份和云同步。
- `ProductionRun` 新增可选 `voiceSettings` / `voiceover` / `subtitles`；删除任务时清理媒体。
- 备份 v3 校验支持配音/字幕元数据；旧备份兼容。
- 音频缺失（例如备份恢复后）会在配音卡提示，重新生成后才能播放/导出。

### 字幕

- 按 TTS 句级时间戳生成 SRT；长句按标点/字数拆分，按时长比例分配。
- 预设：B站 18 字/行、最多 2 行；抖音 12 字/行、最多 2 行。
- 换行优先落在标点处，且保证不丢掉超出行数的文本（交给质量检查报超长）。
- 无 TTS 时间戳时使用估算时间，并在检查与界面标明「估算」。
- 预检新增：配音缺失/失败、配音时长偏差、字幕缺失/失败、行宽、阅读速度、时间戳来源、台词覆盖率。

### 导出包 v2

- 新增 `voiceover.mp3`、`subtitles.srt`、`voice.json`、`subtitle.json`。
- manifest `formatVersion: "2"`，并记录媒体文件、配音时长、字幕条数。
- README 增加媒体文件说明。
- 组合包按每条 run 的目录带入各自的媒体文件；未就绪任务仍用 DRAFT。

### UI

- v2 任务新增「配音与字幕」卡：Worker 状态、音色/语速/音调、生成/重新生成、音频播放器、MP3/SRT 下载、字幕预览与质量统计。
- 阶段轨支持 7 阶段；任务摘要显示配音时长/字幕条数。

## 4. 已知限制

- 字幕使用 TTS **句级**时间戳，不是逐字/逐词强制对齐；长句拆分后按字符比例分配时间。
- 没有 Whisper/本地强制对齐；没有 TTS worker 时阶段阻塞，不生成占位音频。
- 音频依赖局域网/外网访问 Edge TTS 服务；网络失败会阻塞，不会伪造文件。
- 媒体只在本机 IndexedDB，不进入备份/云同步；换设备或清理站点数据后需要重新生成。
- 配音时长检查是提醒：对话配音通常短于分镜总时长；超过或明显过短会提示人工复核。
- v1 任务保持 5 阶段，不强制升级；新建任务默认 v2。
- R6–R7（成本/批量、剪映/EDL/FFmpeg 成片质检）未开工。
