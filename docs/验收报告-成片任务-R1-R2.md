## 1. 本次交付

### R1 · 可追溯

- **阶段工件单独下载**：`script.md` / `shotlist.csv` / `assets.csv` / `checks.json` / `publish.md`，阻塞/草稿状态也可下载；内容来自当前 run 快照，走 Blob，不发网络请求，CSV 保留 UTF-8 BOM。
- **运行事件时间线**：创建、检查、素材、版权、复核、导出、归档、备注、发布绑定/解绑都会追加事件；只记录摘要，最多保留最近 200 条；详情页时间线按时间倒序，默认 8 条、可展开。
- 旧 run 没有 `events` 时按空数组处理；不升 Dexie 版本。

### R2 · 发布闭环

- **发布回填与校准卡**：有发布记录时显示真实播放/点赞/投币/收藏/分享/评论、发布时间、BVID、取数时间、数据来源，以及预测值、预测来源和偏差。
- **不造假**：没有发布记录时显示空状态和「去记录发布」；没有数字化预测时显示「该选题没有数字化预测」且不计算偏差；缺失指标显示 `—`，不补 0。
- **绑定**：`run.publishRef` 只存在本机 run；平台必须一致；优先按 `bvid` 匹配；同一发布记录已绑定到其他任务时必须二次确认；解绑/重新绑定都留事件。
- **深链**：`/?publish=<topicId>` 会在选题看板自动打开对应「记录发布结果」弹窗，打开后清除 query，StrictMode 下防重复。
- **导出**：`manifest.json` 中的 run 自动带 `publishRef`；README 有发布绑定时增加「发布绑定」行；`checks.json` 不写校准数据。

## 4. 已知限制

- 发布绑定只在本机 run 中，不修改 `Topic.published`，不同步云端；换浏览器/设备不会带着绑定走。
- 阶段工件和完整包都不含成片、配音、字幕（R5/R7 范围）。
- 事件上限 200 条；达到上限后较早记录会被截断。
- 同一发布记录被多个 run 绑定时，系统提示并等待人工确认，不做自动“认领”。
- 运行数据不参与云同步，仍按 v1 约定只进本地备份。
- 本次未实现 R3–R7（多流水线/平台变体、素材版权库、配音字幕、成本批量、成片交接）。
