## 1. 本次交付

### 素材库授权元数据

- `LibraryAsset` 新增可选字段：`sourceType`、`license`、`licenseUrl`、`expiresAt`、`allowedPlatforms`、`checksum`、`usageCount`。
- 素材库新增/编辑弹窗可记录来源、授权类型、授权链接、到期日、允许平台和校验值。
- 素材卡片显示授权状态、来源、授权、到期、允许平台；「授权待补」统计未记录/过期/平台范围不足的素材。
- 旧素材没有新字段时显示「未记录来源 / 未记录授权」，不推断授权。

### 槽位关联素材库

- `AssetSlot` 新增可选字段：`assetId`、`assetSnapshot`、`matchStatus`、`rightsStatus`。
- 任务素材清单每镜可「从素材库选择」：按类型/标签/关键词给出建议，仍由用户确认，不自动认定。
- 关联后槽位显示素材库名称、来源、授权、到期、允许平台和授权状态；可更换/取消关联。
- 关联素材会记录 `lastUsedAt` 与 `usageCount`。

### 授权门禁

新增预检项：

| 检查 | 级别 | 触发 |
|---|---|---|
| `asset-rights-missing` | 阻塞 | 关联素材缺少授权类型，或已授权但未记允许平台 |
| `asset-rights-expired` | 阻塞 | 授权到期日已过 |
| `asset-platform-blocked` | 阻塞 | 允许平台不包含当前任务平台 |
| `asset-unmatched` | 提醒 | 槽位已准备但未关联素材库 |
| `asset-rights` | 通过 | 已关联素材且授权可核验 |

- 标记「不需要」的未匹配槽位不产生 `asset-unmatched` 提醒。
- 重新检查、复核和导出前都会刷新授权快照；到期/平台不符会阻止发布包。
- 素材库记录被删除时保留旧快照用于展示，但授权状态按「未记录」处理。

### 导出

- `assets.csv` 新增列：来源、授权、到期、允许平台、素材ID、素材名称。
- 未关联/旧记录显示「未关联 / 未记录」，不补 0。
- 备份 v3 兼容；不升 Dexie 版本；云端仍只同步素材元数据，不含媒体文件。

## 4. 已知限制

- 建议匹配是类型/标签/关键词匹配，不做语义模型判断；仍需人工确认。
- 系统只校验素材库里**记录的**授权元数据，不验证外部合同/授权页的真实性；校验值需人工填写，未自动计算文件哈希。
- 到期日未记录时按「未记录到期」展示，不自动视为过期；授权类型与允许平台必须记录，否则阻塞。
- 允许平台未选择时：自有/CC 视为不限；已授权素材按「平台范围未知」阻塞。
- 素材关联只在成片任务里保存快照；素材库后续修改会在重新检查/导出时刷新，历史包不会被改写。
- `usageCount` 仅在任务槽位关联时累加，打开链接/预览不计。
- 云端同步仍只含素材元数据，不含媒体文件；R5–R7 未开工。
